# IAM500 — Identity and Access Management

Hands-on labs in **Microsoft Entra ID (Azure AD)** and Azure identity security: user lifecycle, groups, external identities, MFA and Conditional Access, RBAC, managed identities, Key Vault, Defender for Cloud Apps, Identity Protection, and app registrations.

| Week | Topic | Report |
|---|---|---|
| 1 | Users, role delegation, bulk provisioning, licensing, custom domains, static and dynamic groups | [week01](week01/README.md) |
| 2 | Google as an external IdP (B2B), MFA via Conditional Access | [week02](week02/README.md) |
| 3 | Azure VM sign-in with Entra ID, RBAC role lifecycle, Smart Lockout | [week03](week03/README.md) |
| 4 | Managed identity and Key Vault, Defender for Cloud Apps, Identity Protection | [week04](week04/README.md) |
| 5 | App registrations, API scopes, enterprise apps, admin consent | [week05](week05/README.md) |

**Skills:** Entra ID administration · Conditional Access · MFA · Azure RBAC · OAuth 2.0 / OIDC app registration · CASB · Key Vault

*All work was done in a temporary lab tenant. Screenshots show configuration only; no secret values are shown.*
